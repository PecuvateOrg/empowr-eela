# Planning — Workspace Index

This workspace contains all pre-build context for Empowr Sessions.

| Subdirectory | Contains |
|---|---|
| `spec/` | Product spec, MVP scope, page-by-page acceptance criteria |
| `architecture/` | System design, tech stack decisions, request lifecycle |
| `decisions/` | ADR log — one file per significant decision |

## When to Use This Workspace

- Before building a new page or feature — read `spec/CONTEXT.md` for scope and acceptance criteria
- Before making a tech decision — log it in `decisions/` first, then update `architecture/CONTEXT.md`
- When onboarding to the project — read all three subdirectory CONTEXT.md files in order
